Hey yall! The following is my submission to Hacklife Hacklub week 1. Enjoy!

Smiley Guy is a simple keychain “tomagatchi”, built with the help of the starbie build guide from half-life, as well as some of my own knowledge. It features:

An SSD1306 OLED module for the screen

Two Buttons for navigation 

DHT11 for temperature and humidity readings

MPU6040 for menu and shake detection 

A rotary encoder for contrast control 

Please Note: the BOM doesn’t contain a PCB as I’m planning on paying out of pocket for it. The PCB IS REQUIRED. Upload the Gerber files to your favorite PCB fabricator to manufacture it.
